# 第三方资源与许可

## MediaPipe

- 运行库：`@mediapipe/tasks-vision@0.10.32`，锁定在 `package-lock.json`。
- 分发文件：`public/assets/mediapipe/vision_bundle.js`（直接复制包内 `vision_bundle.cjs`，仅更改文件扩展名）、对应Source Map，以及包内SIMD和非SIMD的WASM加载器与二进制。
- 许可证：Apache License 2.0，全文保存在 `public/assets/licenses/MediaPipe-LICENSE.txt`。
- 模型：Hand Landmarker，float16，版本1，包含手掌检测与手部关键点模型。
- [模型下载地址](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task)
- [官方手部模型说明与许可证](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf)：Apache License 2.0。
- [官方Web接口文档](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)

## Salamander Grand Piano

- 作者：Alexander Holm。
- 乐器：Yamaha C5钢琴采样。
- 资源来源：[Tone.js Audio Salamander目录](https://github.com/Tonejs/audio/tree/master/salamander)。
- 许可：[Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/)。
- 原始署名与许可声明：`public/assets/licenses/Salamander-README.txt`。
- 许可全文：`public/assets/licenses/CC-BY-3.0.txt`。
- 项目采用C4、D♯4、F♯4、A4、C5五个MP3采样，原MP3文件未修改。其余音符在播放时按半音变调，音量与起音、释放包络在运行时处理。
- 应用内使用指南保留作者、许可及变调说明，构建产物根目录的 `THIRD_PARTY_NOTICES.txt` 同时保留署名。

## 开发与测试依赖

Vite、TypeScript、Vitest、Playwright与Prettier仅用于构建、测试或开发，准确版本见锁文件，各包许可证保留在安装后的包目录中。它们不需要通过公共CDN在演奏时加载。

浏览器集成测试从 [Google官方测试资源](https://storage.googleapis.com/mediapipe-assets/thumb_up.jpg) 下载手部图片到忽略目录 `work/thumb_up.jpg`，作为合成摄像头回放输入。该图片不进入应用构建产物。

## 资源完整性

`public/assets/manifest.json` 记录运行资源的来源、字节数和SHA256；`npm run build` 会先检查文件内容与清单一致，并检查运行库与已安装MediaPipe包版本相符。

重新准备资源使用 `npm run assets`。脚本保留已存在的下载文件，复制锁定包的运行库，并重新生成清单；若文件损坏，应先删除对应损坏文件再执行下载。不要将重新生成清单代替审查意外变更。
